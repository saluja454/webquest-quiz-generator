# WebQuest — Front-End Interview Practice Platform

A responsive quiz app for practising HTML, CSS, and JavaScript interview questions. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies.

## Features

- **Three quiz categories** — HTML, CSS, and JavaScript.
- **Instant feedback** — See if your answer is correct immediately.
- **Explanations** — Learn why the correct answer is right.
- **Score tracking** — Best scores are saved in your browser using localStorage.
- **Answer review** — Go back and study every question after the quiz.
- **Fully responsive** — Works on desktop, tablet, and mobile.

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic markup |
| CSS3 | Styling, layout (Flexbox, Grid), animations |
| JavaScript | Quiz logic, DOM manipulation, event handling |
| localStorage | Persisting best scores between sessions |
